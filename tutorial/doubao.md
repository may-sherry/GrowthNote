# 🚀 豆包 (字节跳动 / 火山引擎方舟) 配置指南

> **推荐指数**：⭐⭐⭐⭐  
> **特点**：字节跳动旗下大模型，国内访问响应极快，新用户赠送海量免费 Token 额度。

---

## 📋 申请步骤

1. 打开浏览器，访问 [火山引擎方舟大模型平台](https://console.volcengine.com/ark/) 并注册/登录账号。
2. 在控制台左侧菜单选择 **API Key 管理**，点击 **创建 API Key** 并复制。
3. 在左侧菜单选择 **在线推理** -> **创建推理接入点**。
4. 选择“豆包通用模型”完成接入点创建，获取你的专属 **Endpoint ID**（接入点名称）。
