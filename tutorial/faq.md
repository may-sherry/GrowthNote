# ❓ 常见报错排查 (FAQ)

如果在测试连接或生成报告时遇到问题，请对照以下常见原因排查：

---

### Q1: 提示 `402 Payment Required`、欠费或连接失败？
* **原因**：大模型开放平台（如 DeepSeek、Moonshot 等）的 API 账户可用余额为 0 元，且没有赠送的体验额度。
* **解决办法**：
  1. 登录该模型的开放平台控制台，前往 **财务中心 / 充值** 页面查看当前可用余额。
  2. 确保账户可用余额大于 0 元（通常充值 2~5 元即可支撑个人几个月的日常 AI 报告生成）。

---

### Q2: 提示 `401 Unauthorized` 错误？
* **原因**：API Key 填写有误、前后复制了多余的空格、或者密钥已经在平台控制台中被注销。
* **解决办法**：
  1. 检查 Key 字符串是否完整无缺。
  2. 建议在平台后台重新生成一个新的 API Key 并重新粘贴。

---

### Q3: 提示 `429 Too Many Requests` 或 `Quota Exceeded`？
* **原因**：该 AI 账户的免费额度已用尽，或者短时间内连续发起请求触发了频率限制。
* **解决办法**：
  1. 登录对应平台的控制台查看账户余额与 Token 消耗情况。
  2. 视情况在平台充值（通常 1~5 元即可使用很久），或切换到其他提供免费额度的平台。

---

### Q4: 提示 `网络连接超时` 或 `URL 错误`？
* **原因**：接口地址 (Base URL) 拼写错误，或者手机当前网络无法连接该服务。
* **解决办法**：
  1. 确保 Base URL 结尾不要带有额外多余的斜杠或路径。
  2. 例如 DeepSeek 请严格填写 `https://api.deepseek.com`。
