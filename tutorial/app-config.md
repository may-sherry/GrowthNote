# 📱 App 内参数填报说明

获取到 API Key 后，请打开手机上的 **《成长小记》** App 进行配置。

---

## 📍 进入配置页面

在 App 底部导航点击 **【我的】** -> 找到 **【AI 报告配置】** 点击进入。

```text
┌──────────────────────────────────────────────────────────┐
│  接口地址 (Base URL):  https://api.deepseek.com          │
│  API Key:              sk-xxxxxxxxxxxxxxxx               │
│  模型名称 (Model Name): deepseek-chat                    │
└──────────────────────────────────────────────────────────┘
```

## 🧪 测试与保存

1. 按照各平台的参数对照表，准确填入 **接口地址**、**API Key** 和 **模型名称**。
2. 点击页面底部的 **【测试连接并保存】** 按钮。
3. 若弹出提示 **`配置正确，连接成功并保存`**，即代表配置顺利完成！
4. 现在你可以前往数据统计页面，一键生成属于你的深度成长复盘报告了！
