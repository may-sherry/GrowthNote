# 🌟 DeepSeek (深度求索) 配置指南

> **推荐指数**：⭐⭐⭐⭐⭐  
> **特点**：性价比极高、推理与逻辑分析能力极强，非常适合做深度ai复盘。

---

## 📋 申请步骤

1. 打开浏览器，访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 并注册/登录账号。
2. 进入控制台，点击左侧菜单栏的 **API keys**。
3. 点击 **创建 API key** 按钮，给 Key 命名（例如：`成长小记`），点击生成。
4. **复制生成的密钥字符串**（注意：密钥只显示一次，请及时复制保存）。
