## 📖 关于这个网站

这是我为独立开发的 Android App **《成长小记 (GrowthNote)》** 搭建的官方网站。

作为一个没有任何商业资金支持的计算机系在读学生，我始终坚持把这款 App 做到：
* **100% 全功能免费**
* **零广告干扰、零强制开屏**
* **纯本地离线优先，尊重用户数据隐私**

为了贯彻这种“零成本、高可用”的极客精神，这个官网也是基于 VitePress 搭建并直接托管在 GitHub Pages 上的，不需要租用任何昂贵的云服务器。
