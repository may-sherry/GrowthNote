# 📖 AI 大模型配置指南

欢迎使用《成长小记》的 **AI 智能复盘与周报** 功能！

为了保证绝对的数据隐私与零广告体验，《成长小记》采用了 **BYOK (Bring Your Own Key)** 模式。这意味着你的数据将直接从你的手机本地发送给对应的 AI 官方大模型，**不经过任何第三方中间服务器**。

---

## 🔒 隐私与安全承诺

> [!IMPORTANT] 安全与资费说明
> - **本地安全加密**：你输入的 API Key **仅加密保存在你的手机本地**，绝不会上传给开发者或任何第三方服务器。
> - **按需计费 / 免费额度**：绝大多数 AI 平台在注册后都会赠送免费额度（如几百万 Token），日常写日志、做每周复盘足够免费使用很久。
